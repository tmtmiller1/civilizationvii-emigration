# Donation records

Documentation of charitable donations made in support of this mod, kept as proof
and **redacted of personal information**. Each receipt is stored as an image and
embedded below so it renders directly on this page — GitHub does not reliably
render PDFs, and a PDF cannot be embedded inline in Markdown.

These files are committed to GitHub but are **NOT** shipped in the Steam Workshop
build — `release.sh` excludes this folder from the packaged zip (and the build's
allow-list audit would reject it as a second safeguard).
